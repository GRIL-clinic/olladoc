    About olladoc
    
        
    olladoc translates .pdf and .docx
          files locally; no data leaves your machine. Powered by
          Ollama and
          Google's TranslateGemma
          by default; any Ollama-compatible model works.
    
        
    
        
    New to Ollama?
    
        
      
          
    1. Install Ollama: brew install ollama — or download from
            ollama.com/download.
      2. 
          
    2. Pull the default translation model:
            ollama pull translategemma
      3. 
          
    3. Start Ollama (menubar app or ollama serve).
      4. 
          
    4. Upload files, pick source/target languages, click Translate.
