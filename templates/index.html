    About olladoc
    
        
    olladoc translates PDF and Word documents using large language models that run right on your computer. Your files are never uploaded anywhere, so even sensitive documents are safe to translate.
    
        
    The translation keeps as much of the original structure as it can, including headings, lists, and text formatting. Tables, footnotes, and comments are translated separately and saved as their own files.
    
        
    olladoc is built on two free tools: Ollama, which runs the models, and Google's TranslateGemma, a model made specifically for translation and used by default.
    
        
    
        
    Getting started
    
        
      
          
    1. Install Ollama from ollama.com/download (or with brew install ollama).
      2. 
          
    2. Make sure Ollama is running. The status bar at the top of this page will show a green "running". If Ollama is not running, click Start.
      3. 
          
    3. If translategemma is not installed yet, click Download translategemma. This is a one-time download of a few GB.
      4. 
          
    4. Upload a document, pick your source and target languages, and click Translate.

    Limitations
    
        
    Like any automatic translator, olladoc is not perfect, so double-check anything important before relying on it. If exact terminology matters, the two-phase workflow gives you a chance to review an automatically created glossary before anything is translated. Spanish and English are the most thoroughly tested languages; review other languages with extra care. Complicated layouts may lose some formatting.
